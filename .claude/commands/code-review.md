# コードレビュー

このプロジェクト（newcode-course-platform）の変更に対して、以下の観点でコードレビューを実行してください。

## 参照すべきドキュメント

- `CLAUDE.md` — アーキテクチャ、ベストプラクティス、ルート構成
- `要件定義.md` — 機能要件、データモデル、画面一覧

## レビュー観点

### 1. アーキテクチャ・設計
- [ ] Next.js App Router のベストプラクティスに従っているか
- [ ] Server Component 優先で、`'use client'` は必要最小限か
- [ ] データ取得は Server Component / Route Handler で行っているか（Client の useEffect で fetch していないか）
- [ ] 要件定義のルート構成・データモデルに沿っているか

### 2. Supabase
- [ ] RLS やアクセス制御が正しく考慮されているか
- [ ] `auth.users` の `role` による管理者判定が適切か
- [ ] 型は `supabase gen types` で生成したものを使用しているか

### 3. セキュリティ
- [ ] 管理者専用ルート（`/admin/*`）は適切に保護されているか
- [ ] YouTube 埋め込みは `youtube-nocookie.com` を使用しているか
- [ ] 認証トークンや秘匿情報がクライアントに露出していないか

### 4. TypeScript
- [ ] `any` や `@ts-ignore` の濫用がないか
- [ ] 適切な型が付与されているか

### 5. パフォーマンス・UX
- [ ] `next/image` で画像を最適化しているか
- [ ] `next/link` で内部リンクしているか

## 出力形式

1. **サマリー**: 変更の概要と全体的な評価（良／要修正）
2. **指摘事項**: 上記観点に沿った具体的な指摘（ファイル:行番号があれば記載）
3. **推奨修正**: 可能な範囲で修正案や代替実装を提示

引数でファイルやブランチが指定されていれば、その範囲を重点的にレビューしてください。
